Zettel Notes supports hardware keyboards. Built-in actions can be triggered with key combinations, and every shortcut can be remapped.

To view or change shortcuts, go to `Settings > Keyboard Shortcuts`.

<figure>
<img src="/assets/img/keyboard-shortcuts.png" alt="Keyboard Shortcuts"/>
 <figcaption>Keyboard Shortcuts</figcaption>
</figure>

## What you can do with shortcuts

- Insert headings [v1.0.70](changelog.md#1070){ .zn-version }
- Open [text snippets](note/editor/index.md#text-snippets-button) [v2.7.9](changelog.md#279){ .zn-version }
- Run any of the built-in editor actions

!!! tip

    On a touch screen without a hardware keyboard, the **meta keys toolbar** editor button shows keys such as Ctrl and the arrow keys, so you can still use shortcuts [v2.9.1](changelog.md#291){ .zn-version }.

## Back up your shortcuts

Custom shortcuts can be backed up and restored with the rest of your [app data](auto-backup.md#other-data-you-can-back-up) [v2.7.9](changelog.md#279){ .zn-version }.
