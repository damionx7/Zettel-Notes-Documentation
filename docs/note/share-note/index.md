A note can be shared as:

- [Launcher shortcut](launcher-shortcuts.md)
- [PDF or HTML](pdf.md)
- [Pinned Notification](notifications.md)
- [via Pandoc as DOCX, EPUB, ODT, HTML](pandoc-termux.md)
- [Zettel Links](zettel-links.md)
- an image [v2.8.8](../../changelog.md#288){ .zn-version }
- rendered HTML copied to the clipboard [v2.9.6](../../changelog.md#296){ .zn-version }
- the note file itself, sent directly to another app (e.g. email or Telegram)
- a template

To copy or move notes to another folder, select them in the [notes list](../../notes-list.md#selecting-several-notes).

!!! tip

    You can also create note widgets. [Read more](widgets.md).
