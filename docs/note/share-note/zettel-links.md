To share a Zettel link, tap the menu button next to the note. Choose `Share > as Zettel Link`.

You can change the format of Zettel Link in `Settings > Notes List > Zettel Link Format`

For a repository named `root` containing `note.md` with ID `123456`, the supported link formats are:

- `znotes://root/note.md`
- `znotes://root/?id=123456`
- `https://thedoc.eu.org/app-links/zettel-notes/root/note.md`
- `https://thedoc.eu.org/app-links/zettel-notes/root/?id=123456`
