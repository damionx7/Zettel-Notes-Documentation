With Zettel Notes, you can display note content directly on your home screen using widgets.
To add a widget, long-press the Zettel Notes app icon and select "Widgets".

Available widgets:

| Widget | Shows |
|---|---|
| Note | The content of a single note |
| Task Note | The tasks in a [task note](../note-types.md#task-note) |
| Recent Notes | Your most recently used notes |
| Folder Notes | The notes in a selected folder |
| Tags | All tags in the repository |
| [Memo](../memo.md) | Your memo, for quick capture |

The note widget can hide its title and change its text size [v2.9.9](../../changelog.md#299){ .zn-version }.
