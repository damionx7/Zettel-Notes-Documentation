The **Memo** is a scratchpad for quick capture: jot something down now and sort it into a proper note later.

!!! note

    Memo was called **Draft Notes** before version 3.1.0.

## Open the memo

You can reach the memo from:

- the **Memo widget** on your home screen ([Widgets](share-note/widgets.md))
- the **right drawer**, from any note ([Navigation](../navigation.md#right-drawer))
- the **Memo editor button** in the [editor toolbar](editor/index.md#editor-buttons)

## Add to the memo

- **Share text** from any app to Zettel Notes and choose to add it to the memo [v3.0.8](../changelog.md#308){ .zn-version }.
- **Long-press the memo editor button** to add text to the memo without leaving the note you are editing [v3.0.8](../changelog.md#308){ .zn-version }.

## Pin, export and import

- **Long-press** a memo entry to pin or unpin it [v3.1.1](../changelog.md#311){ .zn-version }.
- Memo entries can be **exported and imported**, for example to move them to another device [v2.9.9](../changelog.md#299){ .zn-version }.
