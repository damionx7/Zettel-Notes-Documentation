Zettel Notes is available from the Play Store and from its own F-Droid repository.

- [Google Play Store](https://thedoc.eu.org/redirect/zettel-notes)
- [F-Droid repository](#f-droid-repository)

## F-Droid repository

The F-Droid repository carries Zettel Notes, its plugins and the developer's other apps, and delivers updates through your F-Droid client.

1. Install an F-Droid client: [Droid-ify](https://f-droid.org/en/packages/com.looker.droidify/) (recommended) or the [official client](https://f-droid.org/en/packages/org.fdroid.fdroid/).
2. Add this repository:

    ```
    https://thedoc.eu.org/fdroid/repo
    ```

3. Check that the fingerprint matches:

    ```
    B1358F5B942E5676B2935B83F39E3BAA363F3FDA9E53DB62113551D14B09A173
    ```

If downloads are slow, use the [mirror URL](frequently-asked-questions.md#f-droid-downloads-are-slow).
