---
title: WebDAV Synchronization
---

To set up WebDAV sync, go to `Repositories > Setup Sync > WebDav` and enter the WebDAV URL, username and password.

To sync a subfolder, include it in the URL.

!!! tip

    If your server uses a self-signed certificate, tick **Trust Private Certificate**.

!!! info

    Dotfiles and dot-folders (e.g. `.attachments/`) are not synced.


For Nextcloud, see [this FAQ](../../frequently-asked-questions.md#how-to-use-nextcloud-synchronization)
