---
title: Recycle Bin
---

Each [repository](./repository/index.md) has its own recycle bin.

The recycle bin is enabled by default and automatically empties items older than 7 days. You can change this in `Settings` to any value up to 30 days. Set it to 0 to keep deleted files indefinitely.

!!! info

    Restored files return to the folder they were deleted from.
