Share a web page from your browser to Zettel Notes to save it as Markdown. The following options appear in the share menu:

1. **New Note**: create a note from the page content
2. **Add to Note**: add the page URL to an existing note
3. [New Bookmark Note](./note/note-types.md#bookmark-note): create a note that opens the URL
4. **New Video Note**: for YouTube videos
5. **Add Webpage Content to Note**: download the page, convert it to Markdown and append it to a note you choose

!!! info

    To change the default format for bookmark notes, video notes and web clips, go to `Settings > Note Formats`. Video note formats can use a `$description$` variable for the video description [v3.0.4](changelog.md#304){ .zn-version }.

For pages that require a login, use the built-in HTML-to-Markdown converter [v2.6.1](changelog.md#261){ .zn-version }.

## Sharing text and images

- **Text** shared from any app can create a new note, be appended to an existing note, or be added to the [Memo](note/memo.md).
- **Images:** when you share several images at once, they can be added to a single note [v2.9.6](changelog.md#296){ .zn-version }.
- When creating a note from a share, you can choose the subfolder; the last folder you chose is remembered [v2.8.4](changelog.md#284){ .zn-version }.
