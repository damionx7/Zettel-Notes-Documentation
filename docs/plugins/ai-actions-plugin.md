On-device AI actions for Zettel Notes — no API key, no internet needed, runs fully offline on your phone.

- Run built-in actions like summarize, rewrite, or expand on selected text
- Add, edit, or delete your own custom actions
- Everything runs locally, so your notes never leave your device
