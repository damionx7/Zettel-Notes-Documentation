!!! information
    Download from [Play Store](https://play.google.com/store/apps/details?id=org.eu.thedoc.zettelnotes.buttons.chat) or F-Droid

AI chat plugin for Zettel Notes, letting you chat and take notes side by side.

- Capture points from the conversation directly into your notes, no switching apps
- Conversations and notes stay private
- Simple, easy-to-use interface

> **Note:** Requires an [OpenAI API key](https://platform.openai.com/account/api-keys) or compatible server to work. This is an unofficial app and isn't affiliated with OpenAI.
