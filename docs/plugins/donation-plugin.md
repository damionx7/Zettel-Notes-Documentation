!!! info

    Download from [Play Store](https://play.google.com/store/apps/details?id=org.eu.thedoc.zettelnotes.buttons.dummy) or F-Droid

Zettel Notes is free, has no ads and collects no user data. It is built and maintained by a single developer.

The Donation plugin adds no features. Buying it is a one-time way to support development from inside the Play Store, using your usual payment method.

## Other ways to support Zettel Notes

| Option | How |
|---|---|
| One-time donation | [Buy Me a Coffee](https://www.buymeacoffee.com/dr.rohit) |
| Monthly membership | [Buy Me a Coffee membership](https://www.buymeacoffee.com/dr.rohit/membership) |
| GitHub Sponsors | [Sponsor on GitHub](https://github.com/sponsors/damionx7) |
| Paid plugins | Buy a [plugin](index.md) you will use |
| Rate the app | Leave a review on the [Play Store](https://thedoc.eu.org/redirect/zettel-notes) |
| Translate | Help translate the app into your language ([Translations](../translations.md)) |
| Test new versions | Join the [beta programme](../download.md#beta-testing) and report issues |

!!! tip

    Feature requests and bug reports are welcome in [GitHub Discussions](https://github.com/damionx7/Zettel-Notes-Documentation/discussions).
