Introduction

Zettel Notes is a Markdown note-taking app for Android. Your notes stay as plain-text files in folders you control, so no app ever locks you in.

Download Privacy Policy

Why Zettel Notes?

  • Plain-text files. Every note is a separate Markdown, text or Org file that any other app can open.
  • Use your existing notes. Add any folder as a repository and your notes appear immediately.
  • Free, with no ads. No hidden permissions and no collection of user data.
  • Offline first. Everything works without an internet connection; sync is optional.

Getting started

  1. Install Zettel Notes. The app opens with an introductory note.
  2. Open the menu, select Repositories, and add the folder that holds your notes (or start fresh in the app's own folder).
  3. Read about notes, the editor and Markdown formatting.

Features

Writing and linking

  • Markdown formatting with LaTeX, tables and task lists
  • Zettelkasten support: wiki links, backlinks, tags and authors
  • Note types: task, drawing, audio, bookmark and log notes
  • Templates and YAML frontmatter
  • Citation manager for BibTeX and CSL JSON

Organising and finding

  • Multiple repositories with subfolders; MD, TXT and Org files
  • Full-text search and saved searches
  • Sort by name, edit time, creation time, word count or how often a note is opened
  • Bookmark and pin notes, calendar view, gallery and recycle bin

Sync and security

  • Git, Dropbox, WebDAV and SFTP sync with a built-in keys manager
  • Note encryption with a password or PGP key
  • App lock with biometrics
  • Automatic backups

Customisation and integration

  • App themes, Markdown styles and fonts
  • Keyboard shortcuts
  • Share notes as PDF, HTML, launcher shortcuts, widgets or pinned notifications
  • Clip web pages or share text from any app into a note
  • Tasker integration and plugins
